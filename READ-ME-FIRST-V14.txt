LeafTV v14 UI refresh (apply to the same Termux project that built v13).

CHANGES:
- No LeafTV wordmark at top; floating navigation at upper right.
- Larger translucent app cards show REAL installed icons over jewel-tone artwork.
- Green focus outline + gentle zoom; visual updates in Home, Quick Picks and All Apps.
- Saved app ordering, pinning and wallpaper bundles untouched.

INSTALL:
1. cd ~/LeafTV/LeafTV
2. unzip -o ~/storage/downloads/LeafTV-v14-ui-refresh-patch.zip -d .
3. bash UPGRADE-V14-TERMUX.sh
4. bash INSTALL-V14-TERMUX.sh
5. Verify via: adb shell dumpsys package com.leaftv.launcher | grep versionName
   Expected: versionName=14.0

The build still needs all 50 previously requested images. The patch does not remove assets or change the wallpaper downloader. If a fresh download fails, your existing images remain in place.
The APK has not been compiled on this server; the build must finish on your Termux device.
